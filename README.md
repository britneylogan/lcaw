# ✨ LC Aesthetics & Wellness

A living library of LC Aesthetics & Wellness — fonts, visuals, and code that shape the brand across every space.

---

## 🧩 Purpose
This repository centralizes design and development assets for LC Aesthetics & Wellness.  
It acts as a shared source of truth for everything that connects the brand’s digital and visual identity — from typography and web components to automation scripts and creative assets.

---

## 📁 Folder Structure
- /fonts → Brand typefaces (web-optimized WOFF/WOFF2)
- /assets → Shared graphics, SVGs, and visuals
- /components → Shopify & Framer code components
- /snippets → Reusable HTML/Liquid/CSS snippets
- /docs → Brand guides, notes, and reference files

---

## 🌐 Integration Notes
- Fonts and visual assets in this repository are **public** so they can be linked directly in Shopify, Framer, or Instant.  
- Use **raw GitHub URLs** for external linking:  
  `https://raw.githubusercontent.com/britneylogan/lcaw/main/fonts/FontName.woff2`
- Avoid storing any sensitive or internal data — this repo is intentionally **public** for brand accessibility and web integrations.

---

## 🧠 Maintenance
- Keep version history: add updated files instead of overwriting.  
- Use lowercase folder names and hyphens for consistency.  
- Optimize all web assets for performance (`.woff2`, `.svg`, `.json`, `.css`).  
- Confirm font licenses allow for web embedding before linking externally.
